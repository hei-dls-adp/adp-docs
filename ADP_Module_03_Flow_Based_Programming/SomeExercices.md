## Working locally

You must be able to launch the flow located on the module's Git repository using **Node.js**.
- ``adp-docs\ADP_Module_03_Flow_Based_Programming\node_flows``

- This flow is called **Flow 3**.

### Inject / Debug

View the Debug window.

Add an Inject node with its name and view its name in the debug window.

Import the HelloWorld.json flow from the Git repository: ``adp-docs\ADP_Module_03_Flow_Based_Programming\node_flows`` and run it.

Clean up the debug window.

### change

Modify HelloWorld to display **Hello your name**.

### switch
Use one switch node, three inject nodes, and three debub nodes to display the following information:

- Red
- Orange
- Green
